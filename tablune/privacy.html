Tablune — Privacy Policy

Last updated: October 4, 2026

This policy is short because Tablune's design makes it short: the app has no server, makes no network connections, and collects nothing. Your files, their contents, their names, and even the fact that you opened them never reach the developer.

Summary

  • Tablune does not require an account or login.
  • Tablune does not collect, transmit, or store any of your data on any server, because Tablune has no server.
  • Tablune makes no network connections of any kind — not for updates, not for telemetry, not for anything. It contains no HTTP client, no sockets and no networking libraries.
  • There is no analytics, advertising, tracking, or crash reporting in the app.
  • Tablune opens only the files you choose. It never scans your disk, your other documents, or anything you did not point it at.
  • Your original file is never modified. Tablune works on a private copy and writes results only where you ask it to.

What Tablune reads

The files you open, and nothing else — the delimited text files (CSV, TSV) you choose from the file picker, drag onto the window, or open from Explorer, plus any Tablune project or recipe you open yourself.

When you open a file, Tablune copies it into a private working area and does all processing on that copy. The original is read once and never written to.

What Tablune stores, and where

Everything Tablune writes by itself lives in your own user profile:

Recipes are kept under Documents on purpose: a packaged app's local data is removed when you uninstall, and work you saved deliberately should outlive the app. Everything else in the table above is Tablune's own working data, and uninstalling removes it.

  • Working copies. The private copy of each file you open. Removed when you close the file. You can move the working area to another local folder in Settings.
  • Recovery snapshots. Your steps, checks and corrections, saved a few seconds after each change so an unexpected shutdown does not lose your work. An interrupted session is kept for seven days unless you restore or discard it.
  • Projects and recipes. Files you choose to save. A project can contain cell values you corrected by hand, so treat a project file like the data it describes when you share it. A recipe contains settings only — no data, no file paths, and nothing executable.
  • Exports and reports. Files you ask for, written where you choose. A run summary records counts, settings and file hashes; optional reports (issues, removed rows, quarantined records) contain values from your file, and Tablune tells you so before writing them.
  • Settings and history. Your preferences and a short list of recently opened files, which you can clear at any time in Settings.
  • Diagnostic logs. Five small rotating files recording operation names, timings, version numbers and error codes. They deliberately exclude cell values, file names and paths. Nothing is transmitted; if you ever want to send them, Settings can write a ZIP and shows you exactly what it contains first.

Tablune does not claim to encrypt this storage or to erase it securely. If your Documents folder is synced by OneDrive or similar, that folder follows your own sync settings — Tablune itself uploads nothing.

Why Tablune needs "full trust"

The Microsoft Store lists Tablune as using the runFullTrust capability. This is what any traditional Windows desktop program needs in order to run at all — in Tablune's case, to open the files you pick through the standard Windows file dialogs and to run its own background worker process, which does the heavy processing over a local pipe so the window stays responsive. It is not a permission to roam your personal files, and Tablune does not do so. No other capability is declared.

Network use

Tablune makes no network connections of its own, and every data feature works with networking switched off.

The one online element is the Microsoft Store. Windows — not Tablune — checks your licence and handles the trial and the purchase. If you press "Buy once" or "Open Microsoft Store", Windows opens the Store app. Microsoft's handling of that is covered by the Microsoft Privacy Statement. Tablune receives only whether you hold a valid licence and, during a trial, when it ends. Nothing about your files is involved.

Third-party services

Tablune does not integrate with, or send data to, any third-party service, analytics provider, or advertising network.

Children's privacy

Tablune is a tool for working with data files. It is not directed at children and knowingly collects nothing from anyone, of any age — consistent with the no-data-collection design described above.

Your choices

  • Clear the recent-files list, or clear unused working files, in Settings.
  • Delete recovery snapshots by discarding them when the app offers them, or by clearing unused cache.
  • Uninstall at any time. Uninstalling removes the app and its working files; it leaves your own sources, exports, projects and saved recipes exactly where they are.

Changes to this policy

If Tablune ever gains a feature that changes what is stored, or adds any network feature, this page will be updated first and the change disclosed in the app's release notes before it ships. As of this version, no such feature exists or is planned.
