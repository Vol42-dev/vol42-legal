DualDash — Privacy Policy

Last updated: August 30, 2026

This policy is short because DualDash's design makes it short: the app has no server, makes no network connections, and collects nothing.

Summary

  • DualDash does not require an account or login.
  • DualDash does not collect, transmit, or store any of your data on any server, because DualDash has no server.
  • DualDash makes no network connections of any kind — not for updates, not for telemetry, not for anything.
  • There is no analytics, advertising, or tracking software in the app.
  • DualDash requests no Windows permissions at all — no location, camera, microphone, contacts, calendar, or access to your files.

What DualDash reads

To show you what your computer is doing, DualDash reads the following from your own machine, in memory, and displays it to you on screen:

  • Processor, memory, GPU, disk and network performance counters provided by Windows
  • The names and CPU and memory usage of running processes, for the optional per-process list
  • Temperature sensors, where your hardware exposes them (ACPI thermal zones, NVIDIA driver telemetry, or LibreHardwareMonitor / OpenHardwareMonitor if you have either installed)
  • Your Windows time zone data and your light/dark theme preference

None of this is recorded, uploaded, or kept beyond the moment it is shown. The short history graphs live in memory only and are gone when you close the app.

What DualDash deliberately does not read

DualDash asks Windows for no permissions, and declares no device capabilities in its package.

In particular, it does not read Wi-Fi network details. Windows treats the name (SSID) and hardware address (BSSID) of the network you are joined to as location data, because those can be used to work out where a device is. An earlier version of DualDash read them only to show a signal-strength percentage; that reading was removed in version 1.1.0 so the app touches no location-related data whatsoever. Network link speed now comes from the network adapter's own reported rate, which says nothing about where you are.

What DualDash stores, and where

A single settings file on your own device:

Installed fromLocation
Microsoft Store%LOCALAPPDATA%\Packages\Vol42.dev.DualDash_0ghj7dvz72xhr\LocalCache\Local\Vol42\DualDash\
Run directly%LOCALAPPDATA%\Vol42\DualDash\

It holds your chosen time zones and labels, alarms, window position and size, theme, opacity and monitor preferences. If an unexpected error occurs, a diagnostic message may be written to error.log in the same folder; that file is capped in size and never leaves your device. Uninstalling the Store version removes the folder and everything in it.

Why DualDash needs "full trust"

The Microsoft Store lists DualDash as using the runFullTrust capability. This is what any traditional Windows desktop program needs in order to read performance counters, memory status, network interface statistics and per-process usage — the very numbers the app exists to display. It is not a permission to access your personal files, and DualDash does not do so.

Third-party services

DualDash does not integrate with, or send data to, any third-party service, analytics provider, or advertising network. There are no in-app purchases.

Children's privacy

DualDash is suitable for all ages and knowingly collects nothing from anyone, of any age — consistent with the no-data-collection design described above.

Changes to this policy

If DualDash ever gains a feature that changes this policy, this page will be updated first and the change disclosed in the app's release notes before it ships. As of this version, no such feature exists or is planned.
